1. 업무 순서 (월간 흐름)

①품목 마스터품번·박스단위·안전재고 등록
(최초 1회, 신규품 발생 시)
②MES 동기화생산입고·출하 전표 자동 수신
(열려 있으면 5분마다 자동)
③입출고 내역수동 전표 등록 / 엑셀 실적 불러오기
구매입고·불량폐기·조정 등
④재고실사표실사 박스수 입력 → 차이 확인
→ 조정전표 발행으로 전산 = 실물
⑤총괄표 / 수불부월말 확인 → 인쇄(결재) · 엑셀 보관
백업 파일 저장
· 실사 → 조정전표 발행 순서를 지키면 전산재고와 실물재고가 항상 일치합니다. 조정전표를 발행하지 않으면 실사값은 참고용으로만 남습니다.

2. 상단 메뉴 (업무메뉴)

메뉴내용주요 사용 시점
📊 재고수불 총괄표전 품목의 전월이월·당월입고·출하·기타출고·현재고·안전재고 과부족·재고일수·회전율을 한 표로 집계매일 재고 확인, 월말 결재용 인쇄
📒 품목별 수불부품번 1개의 전월이월부터 일자별 입·출고 잔량 원장(Bin Card)특정 품번 이력 추적, 감사·고객 제출
↔ 입출고 내역모든 전표(MES 자동 + 수동) 목록. 클릭하면 수정·삭제전표 등록·정정, 엑셀 실적 일괄 입력
✅ 재고실사표품목별 실사 박스수 입력 → 전산재고 대비 차이·정확도 계산 → 조정전표 발행월 1회 이상 실사, 현황판 사진 입력
⚙ 품목 마스터품번·품명·박스단위·안전재고·기초재고·고객사·보관위치·별칭 관리, 백업/복원신규품 등록, 박스단위 변경, 데이터 백업
· 공통 항목 재고구분(전체 / 현장재고·생산팀 / 출하대기재고·검사실)과 기준월은 모든 화면에 함께 적용됩니다. PC는 소메뉴 바 우측, 모바일은 ☰ 메뉴 안에 있습니다.

3. 소메뉴 버튼 기능

화면버튼기능
총괄표🔄 조회현재 조건(재고구분·기준월·검색·필터)으로 다시 집계
🖨 인쇄결재란이 포함된 A4 가로 양식으로 출력 (결재란 "인" 클릭 시 성명 입력)
📗 엑셀총괄표·입출고대장·품목별수불부 3개 시트를 한 파일로 저장
📄 CSV총괄표만 CSV로 저장
수불부🖨 인쇄선택 품번 수불부 1장 출력
📚 일괄인쇄당월 수불이 있는 전 품목을 품번별 1장씩 연속 출력
입출고➕ 입출고등록수동 전표 등록. 박스수 입력 시 EA 자동 환산. 구분: 생산입고·구매입고·반품입고·재고조정(+) / 출하·생산투입·불량폐기·검사폐기·선별제외·반품출고·재고조정(−)
📥 엑셀실적생산·출고 실적 엑셀(.xlsx/.xlsm/CSV) 또는 복사 붙여넣기 → 컬럼 자동 매핑 → 미리보기 → 전표 일괄 생성 (중복 자동 제외)
📄 CSV입출고대장 CSV 저장
실사표✅ 조정전표발행입력된 실사값과 전산재고의 차이를 재고조정(+/−) 전표로 발행하여 전산재고를 실물에 맞춤. +차이/−차이 전표 구분은 조회조건에서 선택
📷 사진인식현황판(화이트보드) 사진을 촬영하면 AI가 품번·재고수를 판독하여 실사표에 입력. 노란 행은 반드시 확인
🧹 실사값지우기입력한 실사값 전체 초기화 (전표에는 영향 없음)
품목 마스터➕ 품목등록신규 품번 등록. 박스단위를 먼저 입력하면 안전재고·기초재고 박스↔EA 자동 환산
📄 CSV등록품번,품명,규격,박스단위,안전재고(EA),현재고(EA),고객사 순서의 CSV로 일괄 등록/갱신
💾 백업 / 📂 복원전체 데이터(품목+전표+설정)를 JSON 파일로 저장 / 불러오기. 월 1회 이상 백업 권장
🗑 전체삭제입출고 전표 전체 삭제 (품목은 유지). 복구 불가 — 백업 후 실행
관리제외쉼표 구분 품번 패턴(예 54610-*). 등록된 품번은 화면·전표·MES 유입에서 제외
공통🔃 MES 동기화MES 생산실적·출하의뢰서·출하검사 불량을 자동전표로 즉시 수신. 원본에서 삭제·정정된 전표는 함께 정리됨

4. 그리드 · 입력 요령

항목설명
행 선택행을 클릭하면 파란색으로 선택. 총괄표의 품번을 클릭하면 해당 품목 수불부로 이동, 입출고 행 클릭은 전표 수정
품번 검색검색란 클릭 시 숫자판이 팝업. 하이픈·공백 무시 검색(1856628 → 1856-628-1). "가나다" 키로 일반 자판 전환
필터(총괄표)전체 / 안전재고 미달 / 재고 0 / 당월 수불발생 / 장기 미불출(90일 이상 출고 없음)
실사 입력실사(박스) 칸에 박스수만 입력. EA·차이·정확도 자동 계산. 빈칸은 미실사로 처리
품목 마스터 셀 수정품명·규격·박스단위·안전재고·기초재고·고객사·보관위치는 셀에서 직접 수정, 구분은 드롭다운
자동전표(MES/출하앱)작성자 칸에 MES·출하앱 표시. 수정해도 다음 동기화 때 원본으로 복원되므로 수량 정정은 재고조정 전표를 별도 등록
계산식현재고 = 전월이월 + 당월입고 − 당월출고 · 과부족 = 현재고 − 안전재고 · 재고일수 = 현재고 ÷ 일평균출고 · 회전율 = 당월출고 ÷ 평균재고
색상녹색 입고 · 적색 출고/부족 · 황색 기타출고/주의(재고일수 7일 미만, 장기 미불출)

5. 데이터 보관

· 데이터는 이 브라우저(PC)에 저장됩니다. 다른 PC나 브라우저에서는 보이지 않으므로 백업 파일로 이동하세요.
· 브라우저 데이터 삭제 시 함께 삭제됩니다. MES 자동전표는 동기화로 복구되지만 수동 전표·실사값·품목 설정은 백업이 있어야 복구됩니다.
· 월말 마감 순서: 실사 → 조정전표 → 총괄표 인쇄(결재) → 엑셀 저장 → 백업

입출고 등록✕

⚠ 자동전표입니다(MES·출하의뢰서·불량관리·거래명세). 수정·삭제해도 다음 동기화 때 원본 값으로 복원됩니다. 수량 정정은 재고조정(+/−) 전표를 별도로 등록하세요.
